# skills

[English](README.md) · **中文**

给 AI 智能体用的可复用 skill 合集。

[`skills/`](skills/) 下面每个文件夹都是一个独立的 skill：一个 `SKILL.md` 告诉助手什么时候用、
怎么用，再加上它需要的文件。全部是 Markdown，能读文件的助手都能用。

## skill 列表

| skill | 做什么 | 语言 |
|---|---|---|
| [创业参谋 · Founder Guide](skills/founder-guide/) | 12 张按处境组织的打法卡，覆盖创业者最常卡住的决定：需求验证、MVP 取舍、定价、早期获客、大客户销售、定位与强敌、股权与合伙人、招人开人与绩效、团队管理、谈判、评估说法数据与预测、危机决策。 | 中文、English |

## 怎么用

1. **下载**：点本页绿色的 **Code** 按钮 → **Download ZIP**，下载后解压。
2. **支持 skill 的智能体**：把对应 skill 的文件夹（比如 `skills/founder-guide/`）放进你的智能体
   加载 skill 的目录，文件夹名保持不变。
3. **不支持 skill 的聊天应用**：把该 skill 的 `SKILL.md` 内容贴进应用的自定义指令（或项目指令），
   再把文件夹里其余的文件作为项目文件上传。

每个 skill 自己的 README 里有详细说明。
