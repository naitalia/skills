# 招人、开人与绩效

招人、评人、开人常常卡在同一件事上：一开始有没有把期望和标准说清。评估最大的毛病主要是经理没列明期望，辞退前最该先问的是自己有没有招错、带错。两个来源的气质不同，一边给流程和问题清单，一边强调标准要自己定、最后自己拍板，分歧见「两派看法」。

## 速览

- **最关键的问题**：我对这个人的期望写下来并告诉他了吗，辞退前答得出「明确告诉过他吗」吗？这个岗位此刻最需要什么能力，我愿意忍受哪些缺点？要换掉的人，问题能追到我自己的职位定义、招聘或融入上吗？
- **首选打法**：① 招人：写下想要的能力和愿意忍受的缺点，面试时留约八成时间让他讲，按同一套标准核对推荐人，最后自己拍板；② 评什么：把期望写下来告诉他，产出与过程的权重没有法则，但要说得出自己在权衡哪两个变量；③ 要不要开掉一个高管：先查根因，别只拿「表现不佳」当理由，比如职责定位清楚吗、有没有让他融入、公司规模是否已扩大到约 4 倍；决定后逐个争取董事会支持，同一天按顺序宣布。
- **最常见的坑**：评估没列明期望，意见含糊、没说怎么改、太多意外；为省事破例（两人共管一个岗位、不做考核和反馈、对拿到别家 offer 的人过度补偿），日后往往要连本带利还；辞退高管只说表现不佳，裁员时把原因说成考核、把辞退推给别人。
- **证据**：全部来自两位资深管理者的个人经验和少量自己挑的案例，没有对照数据；面试问题清单没检验过预测得准不准，「开高管是自己招错」「四条招聘标准」是强论断，证据只是提出者自己的经历。
- **不在这张卡里**：挑裁谁、裁多少、补偿多少、法律程序和通知期；要换的是联合创始人时怎么办。

## 先问这几个问题

1. 我对这个人的期望写下来并告诉他了吗？要辞退他之前，我答得出「明确告诉过他吗」吗？
2. 这个岗位此刻最需要什么能力，我愿意忍受哪些缺点？
3. 我评的是他的绩效，还是被「见多识广」「很有潜力」这类形象说服了？
4. 数字漂亮、人员流动却高、抱怨又多时，这些数字反映的是这段时间的活动，还是更早的活动？
5. 要换掉的人，问题能追到我自己的职位定义、招聘或融入上吗？
6. 他不认账时，我要的是他同意我，还是他愿意去做？

## 打法

### 1. 招人：先定标准，再面试，再核对，最后自己拍板

面试风险和失败率都高，其中一个来源明说再小心也只是增加运气；另一个来源把先想清楚要什么看作整个招聘里最重要的一步。
1. 先想清楚：这个人第一个月做什么、你期望他为什么加入、你要他马上扩大团队还是明年只招一两个人。没干过这个职能的，最好亲自干一阵；也可请做得出色的人谈、参与面试，但决定不能交给专家。
2. 写下想要的能力和愿意忍受的缺点。一个来源的四条标准：本职能是否顶尖、经营能力、对公司方向有没有重大贡献、在团队里是否高效，按岗位调权重。别凭外表感觉，别找想象中的完美人选，别因为「没有弱点」而录用。
3. 面试时你掌控场面，留约八成时间让他讲；把话题拉到你们都熟悉的事上，请他讲做过什么、为什么这么做、重来会怎么改，他离题就打断、道歉、转话题。
4. 用问题收集四类信息：专业知识和技能、运用的能力、知与行之间的差距（从失败中学到什么、现职的问题）、工作价值观。可以直接问他对自己水平的评价，听措辞和肢体语言；不懂他的专业时，先介绍你熟悉的流程，再让他结合专业解一道题。让他发问能看出准备程度，但不是保险——有人把年报背熟、问题精辟，录用后表现极差。
5. 核对：创始人亲自按同一套标准查推荐人；找他没提到的人谈极有效，看的是他是否符合标准，不是评价正负；不认识的推荐人就拉长通话、找共同经历。
6. 分两个面试小组：一组判断是否符合标准，一组判断能否融入、录用后谁的支持关键；每场后讨论，统一对标准的理解。最后你自己拍板——一致同意的决定几乎总倾向「没有弱点」的人。
7. 招大公司背景的主管，警惕两种不匹配：节奏（习惯等邮件和排好的会）、技能（擅长在现成机构里优化，而不是从零建流程）。面试问三件事：第一个月做什么（警惕只强调学习、等分配任务的人）；这份工作和现在有何不同；为什么加入小公司（警惕首要动机是股权）。入职后每天一次带着问题的会面，提不出问题就要考虑换人（这一条很严，用之前先看你有没有给够信息）。
- 做到什么程度算完成：你写得出标准和愿忍的缺点，每条标准都有问题或推荐人的印证。

### 2. 评什么：先写期望，再权衡产出与过程

1. 先把期望写下来告诉他；对管理者，把你对他们的期望（一对一、给反馈、培训员工、认同团队目标）直接说清。
2. 看两类东西：产出（能图表化的结果）和过程（有没有为眼前目标压榨人、有没有培养人、有没有处理好让部门运转的琐事）。两者的权重没有法则，可以是 50:50 也可以是 90:10，这个月和下个月也可以不同，但要说得出自己在权衡哪两个变量。
3. 产出数字反映的往往是更早的活动，来源的例子里时差约一年；数字漂亮却人员流动高、抱怨多，别被数字说服。
4. 评经理要同时看他本人和他的部门，以及他对下属做了什么；评绩效不评潜力，评价不要高于部门的表现。
5. 别以为小公司不需要评估：任何在乎运营绩效的组织都需要，哪怕只有两个助理。
- 做到什么程度算完成：你说得出产出和过程各占几成，评价没有高过他部门的表现。

### 3. 绩效面谈：为提高他的未来绩效而谈

面谈不是把书面报告再念一遍，也不是把观察到的事实全倒出来，多不等于好。
1. 评估稿你自己写，他先写的自评只作参考；材料看进度达标率、每季目标达标率和一对一会议笔记。
2. 拿一张白纸，先不排优先级，把与他绩效相关的事全写下来；再找条目之间的关系（同一问题的不同面貌、弱点为何摆脱不了、优势如何保留），这些关系就是要传达的信息，每条都要有他做过的事支撑。
3. 删到他一次记得住的几条（列 7 点他只接得住 4 点，其余是白说）。即使会让他意外，只要有助于改进就要说；表现好的人也要写改进建议，拿他做过的事与事后总结出的更好做法作比较。
4. 面谈前先把书面稿给他：谈后才给，他会为没听到的内容讨价还价；谈中给，他急着往下读，无法专心。
5. 谈时坦诚、倾听、放下自己：当面褒扬并不比批评容易；看着他，观察语气和肢体反应，直到确信他懂了；把你的不安和愧疚放一边。
- 做到什么程度算完成：他的反应让你确信他听懂了，并且知道下一步要改什么。

### 4. 他不认账、不肯改：要行动，不要求他同意

这类面谈本质上是用冲突的形式解决绩效问题；除非他彻底转变，否则最终该请他走。
1. 先自查：期望说清了吗，给过反馈吗？没有的话，先补，不然你答不出「明确告诉过他吗」。
2. 判断他在哪个阶段：忽视、否认、怪罪他人、担责、找办法（阶段划分是据正文复原的，原图可能分得不同）。用证据让他不能再装作没这回事；他还在否认或怪罪时，别急着谈办法，别走得比他快。
3. 他愿意行动就可以接受，哪怕你不满意。来源里评估者第一次拼命想说服对方，对方说反正已经答应照做，他才明白自己追求的只是心里舒坦。
4. 卡在怪罪他人时才用职权，并明说：你知道他不同意，也许他对，但为了公司要他照做；之后仍要争取他的承诺、观察他的表现。
5. 他既不同意也不改，来源没写后续步骤，最接近的是请他走人。

### 5. 要不要开掉一个高管

1. 先查根因，别只拿「表现不佳」当理由：职责定位清楚吗；是不是凭感觉招人；看重的是长处还是没有弱点；是不是按高于眼下需要的标准招；是不是把职位类型化；他的抱负与公司目标是否相悖；有没有让他融入；公司规模是否已扩大到原来约 4 倍（这时工作变成了全新的工作，既不是他无能，也不是系统错误）。
2. 告知董事会：先逐个打电话争取支持，批准补偿方案（高管应比普通员工更高），保护被辞退者的声誉；别在董事会上突然宣布，尤其当他是董事推荐的。
3. 面谈：稿子写好或预演；复查他的书面考核与你掌握的数据是否一致；原因清楚、语气果断（说「我已决定」，不说「我认为」）、补偿具体；宣布方式最好由他定。
4. 同一天按顺序宣布：直接下属、其他高管、全公司，最好一两个小时内；先安排好汇报关系，一般明智的做法是你暂代其职；正面表述，不贬损他。事后检查并改进招聘。

### 6. 裁员：六步

适用于因公司没达成计划而裁员；若唯一原因是个人绩效，则另当别论。
1. 先稳住自己的头脑：员工里可能有人认定你不是在撒谎就是蠢，这种压力就是你要扛的。
2. 一旦决定就尽快执行，别让消息走漏，否则管理者会被员工追问，只能不知情、撒谎或沉默。
3. 只传一个原因：公司没实现计划。别说成借机考核绩效，一次裁员就能让「请相信我」式的信任坍塌，重建只能说实话。
4. 培训管理者：自己的人自己辞退，不推给人力、更严厉的同事或外包；每人备好三件事——简要说明局势与个人表现无关、指出人数过多且裁员不容商榷、福利补偿细节了然于胸。
5. 执行前向全公司讲话，话是说给留下来的人听的；对被裁者给足尊重，但别过度道歉。
6. 事后别躲起来：在公司露面、交谈、帮被裁的人搬东西，让他们知道你感激。

### 7. 最得力的人提辞职

这套指引针对的是敬业却觉得没被赏识的人；为钱而走、或拿跳槽当升职借口的人不在范围内。
1. 马上放下手边的事请他坐下，让他讲完，不争辩、不说教、不动气，目的是找出真正的理由；别当场想改变他的想法，先争取时间，并兑现你承诺的事。
2. 找上司求援，把公司当整体，必要时调岗；他若已拿到别家的 offer，帮他想清楚对现任上司和同事的承诺。
3. 开条件之前先问：这是我本来就该给的，还是被 offer 逼出来的？后者的条件容易传开，团队可能学到拿 offer 要挟才能涨薪（这是提出者设想的情境推演，不是统计）。

## 常见的坑

- 评估没列明期望；意见含糊、避免负面、没说怎么改、只看最近、太多意外。
- 对明星只找优点、不提改进，对差的人写长篇大论；或把下属的自评改改格式交回，他会觉得被欺骗。
- 为省事破例：一个岗位两人共管、怕有大公司的感觉而不做考核和反馈、对拿到别家 offer 的人过度补偿，日后往往要连本带利还；提出者也承认这类交换有时有道理，关键是记账并负责。
- 辞退高管只说表现不佳；裁员时把原因说成考核，把辞退推给别人。

## 两派看法

两位提出者气质不同：一位给出可照着走的流程和问题清单，一位强调标准要自己定、缺点要自己权衡、最后一个人拍板。但两边都没给公式——前者明说产出与过程的权重没有法则，面试再小心也只是增加运气；后者明说做决定是孤独的。分歧主要在三处。

**不行的人，责任落在谁身上。** 一派：前提是问题出在员工身上（没有谈上司自己的责任），用证据让他走出忽视、否认、怪罪，肯行动就够，卡住才用职权，除非彻底转变否则请他走。
另一派：多半在公司，开掉高管通常是自己的招聘或融入系统出了问题，先查职位定义、标准、融入和规模变化；这是提出者的强论断，证据只是他自己的经历。
还有第三种声音：内部分歧要严肃指出又留改正的机会，只有对方坚持并扩大错误才发展成对抗；它没回答「谁来认定他在坚持错误」。

**招人靠问法，还是靠先定标准。** 一派：你掌控面试，用问题收集四类信息，再找推荐人核对。
另一派：先写下想要的能力和愿意忍的缺点，一致同意的决定几乎总选没有弱点的人，最后一个人拍板。

**骨干要走，怎么留。** 一派：立刻重视，必要时提升或调岗，这是你对整个公司的责任。
另一派：为留住拿到别家 offer 的人过度补偿，条件会传开，等于欠下一笔账。

怎么选（判断，条件取自来源）：第一，先过一道自查——期望说清了吗、培训和反馈给了吗、岗位定义清楚吗；过了关、问题仍在他身上、你又有职权，再走「阶段加职权」的路线；若是规模扩大后不再胜任，不归咎任何一方。第二，内部分歧只在双方仍有共同目标、仍在同一组织、对方还有改正可能时走缓和路线。第三，你熟悉这个职能，四类信息的问法可以直接用；你没干过，先定标准、借专家搭桥，因为问题清单替你判断不了他讲得对不对。第四，条件是你本来就该给的认可或晋升，就马上做；如果是被逼出来的，欠账会找上门。

## 什么时候这套不管用

- 没有产出数字、也没有按年累积的指标（十几个人的团队可能是这样）：产出与过程的权衡没数据可套；没有数据却必须下判断时靠什么，来源没写。
- 没有正式薪酬和晋升周期的早期团队：评估的杠杆要自己重新找（推断）。
- 问题不是能力或绩效，而是欺骗、违规等个人行为：来源没讨论。没有董事会、或要换的是联合创始人时，「先通知董事会」要换成别的对象（推断）。
- 容忍候选人的文化适应性差，来源是以公司正处于苦苦挣扎的「战时」为前提的；要快速扩张时，要的反而是曾让同等规模公司迅速壮大的人。
- 裁员六步只管怎么说、谁来说，不涉及挑人、裁多少、补偿和法律程序；来源是海外公司的经验，各地劳动法对通知期、补偿和程序有硬性规定，要另找律师。

## 例子

- 一位经理的部门销售额激增、净利提高，但人员流动率比以往高得多、下属常抱怨；上司被漂亮的数字说服，给了极佳评价。次年增长停滞、部门更动荡，上司事后断定前一年的评价错了——产出指标反映的是更早的活动。
- 一家软件公司招销售主管，面试二十多人都不够格，最后聘了形象和履历都不像、与公司文化适配很差的人，董事会和多数部门主管都反对。创始人事先亲自管了几个月销售才弄清要什么，核查了几十封推荐信，专门核实了他最大的弱点，又判断公司正处于苦苦挣扎的「战时」，才决定忍受。讲这个案例的人称结果验证了判断，但这是他自己挑的一次成功。
- 一家公司连续三次大规模裁员，共失去数百人，仍保住了文化和最优秀的人，创始人事后总结出六步。他自己说是特例，有位投资人认为连续裁员后公司几乎不可能取得巨大成功。

## 证据有多硬

- 全部来自两位资深管理者的个人经验和少量自己挑的案例，没有对照数据。
- 面试问题清单是一群经理的共识，没有检验过预测得准不准，提出者自己两次录用后看走眼；评估面谈的毛病清单来自让一群经理回想自己收到的评估。
- 裁员六步来自一家公司的三次裁员，没有对照，分不清是方式正确还是业务转机等别的因素；「开高管是自己招错」「四条招聘标准」是强论断，证据只是提出者自己的经历。
- 大公司主管的情景和管理欠账的三个例子是提出者设想的，不是统计；有几个数字在来源中错位，是还原的。

## 一页清单

- [ ] 对每个人（尤其管理者）的期望写下来并告诉了他
- [ ] 招人前写下想要的能力和愿忍的缺点；面试八成时间他讲；推荐人按同一套标准核对；自己拍板
- [ ] 评估稿自己写：白纸写全、找关系、删到他记得住；面谈前先给书面稿
- [ ] 评经理看他的部门，评价不高于部门表现；产出数字是否反映更早的活动
- [ ] 辞退前先问：他清楚被期望做什么吗？我是不是招错、带错？
- [ ] 不认账的人：先判断阶段，要行动不要同意，卡在怪罪时才用职权并说明
- [ ] 换高管或裁员：逐个通知董事会；同一天按顺序宣布；裁员只讲一个原因、自己的人自己辞退
- [ ] 骨干提辞职：放下手边的事听完，不争辩，争取时间；想想条件是不是被逼出来的

## 这张卡没覆盖的

- 挑裁谁、裁多少、补偿多少、法律程序和通知期
- 薪酬、股权怎么跟绩效挂钩
- 没有任何产出数据的早期团队怎么评估
- 要换的是联合创始人时怎么办
- 个人失德、欺骗类问题怎么处理
- 评估稿的具体格式范例；培训课程怎么设计；「新增了多少高效员工」怎么衡量
