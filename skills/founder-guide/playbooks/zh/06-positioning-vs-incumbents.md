# 定位与面对强敌

和大公司撞上时，先别比资源，先问你们在客户心里各占什么位置、对手有哪些动不了的地方。品类已经成形时，办法是找一个客户心里没人占的位置，再在一个更窄的群体里做得比对手好；市场本身还不存在时，办法是把计划写成学习计划，并给自己留出再试一次的余地。这两套打法互相顶着，所以第一步是判断你处在哪种局面。

## 速览

- **最关键的问题**：品类已经成形、客户心里有现成类别，还是客户还不知道怎么用的新市场（判断）？我要占的位置在客户心里真是空的吗，他会不会一句话把我归进已有的类别？计划里哪些假定是知道的、哪些是猜的，钱够试几次？
- **首选打法**：
  - **先看清对手：强在哪里，哪里动不了**：找对手最固化的假设和利益安排（比如渠道商、利润结构让它很难跟进你切入的位置，来源没给这种反转何时会发生的判据），估它拦截你要多久，你的窗口（判断）是在拦截生效前把位置扎下来。
  - **占客户心里没人占的位置**：不做更好的跟风；先检验这个位置在客户心里是否真是空的、他会不会一句话把你归进已有类别，并愿意舍掉一部分客户。
  - **市场还不存在时写成学习计划**：列出关键假定并标明哪些是猜的，先测最关键的假定，再投昂贵、无法回头的钱，留够第二、第三次尝试的资源（来源没说多少才算够）。
- **最常见的坑**：做「更好」的跟风、又想满足所有人；一条路都不选定、低价特色覆盖面三头都想要（会被两头蚕食）；把新市场里的第一个预测当真、一次押完。
- **证据**：多为挑选过或事后归类的公司案例加结构推理，没有对照数据；「不存在的市场不能分析」靠提出者一句数字缺失的「研究已经显示」加三个公司案例，有幸存者偏差。
- **不在这张卡里**：大公司已经进场、开始降价或模仿之后，被拦住的挑战者具体怎么应对；B2B 或软件产品怎么找到「空位」的维度、怎么事前确认空位真的空着。

## 先问这几个问题

1. 我面对的是已经成形、客户心里有现成类别的品类，还是客户还不知道怎么用的新市场？这决定走下面哪套打法（判断）。
2. 对手的强来自规模和成本，还是来自客户心里的位置？它的渠道商、利润结构、内部想法，允许它跟进我切入的位置吗？
3. 我要占的位置，在客户心里真是空的吗？他会不会一句话就把我归进已有的类别？
4. 我是不是低价、特色、覆盖面三头都想要？我敢不敢舍掉一部分客户？
5. 对手发现我的概念后，多快能降价、另起牌子来堵？他内部有没有人拖后腿？
6. 计划里哪些假定是知道的，哪些是猜的？钱够试几次？

## 打法

### 1. 先看清对手：强在哪里，哪里动不了

大公司的实力主要是产品在客户心里的位置，不是规模；在别人先占位的品类里后入场，通常打不赢。这个「通常」来自挑选过的公司故事，不是系统样本。
1. 找对手最固化的假设和利益安排：最坚固的地方常是最脆弱的着力点。例如它的渠道商在高端赚得多、觉得小产品有损形象，它就很难跟进你切入的低端。来源没给这种反转何时会真发生的判据。
2. 估它的拦截：来源给大公司的处方，是趁你的概念还没在客户心里扎根就拦住它：降价、另起新牌子、拓宽名称。你的窗口（判断），是在拦截生效前把位置扎下来。提出者也观察到多数领导者反应迟钝、对对手的进步不以为然、内部把新业务看成抢饭碗，这是你能押的地方，但只是概率；他举的拦截例子都是领导者赢的一边。
3. 别把对手当固定的：对手有能力也有动机调整时，你的动作会改变他的反应；法规、物理约束这类确实固定的东西除外。别拿相对位置当绝对状况：赢过对手不等于你赢，非零和的局里你可能比对手强而两边都在变差；不过现实里不少局面接近零和（固定预算、单一岗位），先判断是哪一类。
- 做到什么程度算完成：你写得出对手想堵你会怎么做、要多久、内部谁会拖后腿，以及它的哪项利益安排让它不会跟进（判断）。

### 2. 别做更好的跟风，去占客户心里没人占的位置

对领导者有效的办法对跟随者不一定有效；跟风产品把重点放在更好而不是速度上，达不到销售目标；跟风有时管用，只在领导者没来得及建立定位时。
1. 先过五问：位置在客户心里还是在我的产线里；别人是否已先建立认知；他会不会一句话把我归进已有类别（第一种无色威士忌在客户心里不算第一，因为早有杜松子酒、伏特加这类白色烈酒，销量只有预期的三分之一）；这个位置要不要他改变根深蒂固的观念；我是不是又想满足所有人。
2. 沿维度找入口：尺寸、价格（高或低）、性别、年龄、时段、渠道、重度使用者。同行都朝一个方向走时，机会常在相反方向。例子都是消费品牌，B2B 里要换成行业、规模、使用场景（推断）。
3. 高价位置得用真正的差异化撑，且要第一个建立；新产品往往适合低价位置，老产品、尤其客户对维修服务不满的，高价往往更好。
4. 愿意舍掉一部分客户：竞争者太多时，想满足所有人根本办不到。
5. 占住之后：时机比创意重要，晚了约二十年的新牌子只好放弃；别把品牌延伸到别的业务；放弃已有定位，份额会塌。
- 做到什么程度算完成：你能用一句话说出「我是 X 里第一个 Y」，潜在客户听完不会把你归进已有类别。

### 3. 资源不够打全行业：选一条路做到底，被压住就换战场

总成本领先、差异化、集中于某个群体，三种打法需要不同的资源、技能和组织安排，所以要选一种长期坚持；三种都不沾，会被两头蚕食。
1. 排除法：成本领先要较高份额、前期投资和承担启动亏损，没份额没资本的创业公司基本走不通，剩下差异化与集中（判断）。
2. 选集中：挑一个更窄的买方群体、产品类别或地域，可以挑对手最弱、替代品最少的，把每个职能都围着它改；我的读法是这属于运营细节，不是定位口号（判断；例：专做专业涂料的公司给油漆工设免费咖啡室，一加仑也快送）。前提是你服务这个群体确实比大布局的对手更好或更省。
3. 认下代价：份额常有上限，利润和销量要权衡；风险是与大布局者的成本差拉大、群体与整体需求的差异缩小、对手在你的群体里再细分。
4. 主场被强势品牌压住时，可以放弃它，把最后的钱集中打一个大玩家没覆盖的点，再用这个点的胜利造势。可迁移的是这个结构，不是当年规则混乱时的打法。

### 4. 新兴行业：别急着围堵，先判断早进值不值

1. 瓶颈若在信誉、标准、买方疑虑这类公共问题上，各家成败相互依存。先行者别把过多资源花在保护份额、对付不太可能成为骨干的对手上；把力气放在塑造规则、推动标准（标准化与保持产品独特之间要判断，并非一律推），必要时用许可之类鼓励特定对手进入。偶尔激烈回应仍有必要。
2. 早进还是等，对照条件。适合早进：声誉对买方重要；学到的东西难模仿、不会被接连的技术更替作废；客户忠诚度高；越早锁定原料和渠道越有成本优势。该等一等：早期的竞争规律与日后完全不同；开创市场的成本高、收益不能独享；早期对付的小对手很快被更可怕的后来者取代；技术变化让早期投资作废。条件只列不排权重。
3. 早期壁垒主要来自风险承受力、创新能力和判断，资源多少其次；行业成熟后壁垒迅速消失，大企业带着规模经济进来。
4. 判断谁最先买（只适用于买方群体已经存在的情形，判断）：性能优势对他多迫切；成本优势多大；出故障的代价多高（高的更犹豫）；换用成本多高；他把技术变革当机遇还是威胁；决策者选错要担多大私人风险。别只看性能优势。
5. 市场已经存在时，用几个自洽的情景代替单点预测；资源足就促成最有利的那个，资源有限或不确定性明显就保持灵活。

### 5. 市场还不存在时：把计划写成学习计划

不存在的市场不能被分析，用途在形成时是不可知的，这类市场里最初的策略一般是错的。
1. 把计划依赖的每个假定（用户是谁、用在哪、需求量多大）列出来，标明哪些是猜的。
2. 投下昂贵、无法回头的钱（专用产线、专门的设计特性）之前，先测最关键的假定；设计上用易重构的模块。
3. 看用户怎么用，别听他们怎么说；盯着计划外的成功，新市场常从那里长出来。
4. 留够第二、第三次尝试的资源，或与信任你的支持者、投资者的关系：一个想法的失败不该成为公司的失败。来源没说多少才算够。
- 做到什么程度算完成：每条关键假定都有检验办法，预算没有一次押完。

## 两派看法

**一派：先选定一个位置，然后做到底。** 定位一派要先在客户心里占一个位置，为此舍掉一部分客户、有损失也在所不惜；三选一一派要选一种打法长期坚持，三种都不沾就是进退两难。
**另一派：新市场没法事先分析，只能边试边学。** 市场不存在，就谈不上先分析；最初的策略一般是错的，成败看谁能活到第二、第三次尝试：这一派说，在找到可行策略之前就用完资源或信用的公司，就是失败的公司。
夹在中间的是情景分析（判断）：用几个自洽的情景代替单点预测，但它自己也留了口子，资源有限或不确定性明显就保持灵活。

分歧落在三处：位置是先占还是试出来；打法是选定做到底，还是首选多半会错；先分析情景，还是根本无从分析。

怎么选（判断）：看这个品类在客户心里是否已经存在。已成形、有已知用户和可比的对手，就先选位置、选一条路，做到底，别同时押几处。还不存在、用户不知道怎么用，就把位置当作待检验的假定，留资源做第二次。真实产品常介于两者之间，怎么归类要自己判断。押上最后一笔钱打一个点的做法与留资源冲突，分水岭大概也是还在不在摸索位置。

另有三处小分歧，条件不同（判断）：规模算不算实力（定位一派说位置才是，三选一一派把规模经济当成本优势的一条来源）；抢第一还是有条件地早进（见打法 4）；拦截还是不围堵（前者是品类里出现新概念时领导者的快速回应，后者是新兴行业整体增长被公共瓶颈卡住时的资源分配）。

## 什么时候这套不管用

- 对手的拦截若赶在你扎根前，后入场的大公司也能赢；变化也能让领导者丢掉位置。
- 找空位的例子几乎都是二十世纪七十到九十年代的美国消费品牌，空位是事后看出来的；软件、平台类市场是否成立要自己验证。
- 三选一不适用所有行业：大宗商品里一切都与成本竞争有关，低成本也未必与差异化冲突。在来源的例子里，进退两难是事后诊断，不是事先判据（判断）。
- 位置不是永久的：时间会销蚀既有的高价定位。
- 学习计划只在市场确实不存在时成立；已知市场里，来源自己说有计划、有研究才是关键。
- 没有已固化假设的早期系统，没有软肋可打（判断）。

## 例子

- 一家体量大得多的饮料公司，在别人先占位的品类里推出同类饮品，销量始终不到先占位品牌的六分之一。证据是几个挑选过的故事。
- 一家外国小型摩托车厂按调研，为陌生的大市场设计了快速大马力的车，几乎被保修费拖垮。派驻的三名员工自己骑小排量车，邻居问哪里能买，成了转向的起点；他们与总部多次争论才说服转向，之后才靠工程和制造不断降价。当地一家老牌高端品牌想用进口小发动机车型跟进，被自己的经销商抵制：高端利润大得多，又觉得小车有损形象。转述来自当事人，数字全缺，也是后来成功的案例。
- 一家大公司的微型存储项目，三年收入目标定得很高，按预测押了产能和抗震设计；头两年销量只有预测的一小部分，销量最大的应用全在计划之外，真正的需求来时已没有资源。项目经理回头说，最大的错误是总觉得自己的预测对。

## 证据有多硬

- 定位一派的论据是挑选过的公司故事和一张只给结果的图，讲的是消费品和办公设备；空位怎么在事前发现，几乎没说；入口清单是从案例归并出来的，没有排序，也没有适用条件。
- 三选一的案例是事后归类的二十世纪七十年代前后的工业品公司；提出者自己也承认关系不适用所有行业，还有反例。集中战略的例子也是已做成公司的事后描述，怎么选群体、怎么确认自己服务得更好，来源没给办法。
- 新兴行业的围堵与时机，靠结构推理加几个行业例子，没有比较围堵与开放结果的数据；时机条件不排权重，也没考虑创业公司的钱能不能撑到市场长大。
- 「不存在的市场不能分析」靠提出者一句研究已经显示（数字缺失）加三个公司案例，有幸存者偏差；摩托车案例的数字全缺。
- 「最坚固的地方最脆弱」有力，但来源没给何时反转的判据。另有一个主张认为先把抽象逻辑想透再动手，它的主要例证有史实错误，暂挂，不拿来支持先分析一派。
- 押最后一笔钱打一座城，讲这个案例的人把一部分成功归于当年的混乱规则，同样孤注一掷而失败的不在来源里。

## 一页清单

- [ ] 判断过：品类已在客户心里成形，还是市场尚不存在
- [ ] 写出「我是 X 里第一个 Y」，并想过客户会不会把我归进旧类
- [ ] 低价、特色、覆盖面只押一个，或选定一个窄群体，并知道要舍掉谁
- [ ] 估过对手拦截的速度和内部阻力
- [ ] 新兴行业：早进与等待的条件都对照过，想过谁最先买
- [ ] 新市场：关键假定已列出并有检验办法，预算没有一次押完

## 这张卡没覆盖的

- 大公司已经进场、开始降价或模仿之后，被拦住的挑战者具体怎么应对
- B2B 或软件产品怎么找到「空位」的维度，怎么在事前确认空位真的空着
- 定位怎么落到文案、官网和销售话术上
- 平台、网络效应类市场里的竞争
- 学习计划要留多少资源才够，怎么向投资人讲
- 具体产品属于已知市场还是不存在的市场，怎么判断
- 向对手开放技术或授权的具体做法与风险
