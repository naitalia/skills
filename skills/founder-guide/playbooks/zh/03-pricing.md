# 定价

这张卡讲的是买家怎么读价格，不讲新品具体该定多少，后者来源里没有。核心判断：买家心里没有一张固定的价签，他的感受随参照点、说法和场合变；但其中几项效应后来被重做得很弱，所以下面每一招都先当成要在你自己页面上测的假设，不是保证有效的杠杆。

## 速览

- **最关键的问题**：买家对这类东西有没有自己的参考价（常买、懂行的人，你的数字能挪动的范围很小）？买家能不能走开、转去别家、直接比价（来源里的实验对象多半走不开）？手里的「愿付价」是问出来的单个数字，还是真付了钱？
- **首选打法**：
  - **别把问出来的愿付价当固定价签**：问卷或访谈得到的数字只是依赖提问方式的读数；同一方案换种说法再问，反应变了，说明测到的一部分是说法而不是偏好（判断）。
  - **设档位**：第三档可能转移份额，但只当成要测的假设，在自己的定价页上对照真实购买，不看纸面选择。
  - **涨价或降价前查参照点**：写下买家此刻的基准，判断你的动作会被读成得还是失；来源没把这个框架落到具体价格动作上，这一步是推断。
- **最常见的坑**：把「摆个高价就能抬高愿付价」当成已证事实；把实验里的倍数当定价参数；不加改动地搬到订阅、软件、企业客户。
- **证据**：较硬的部分之一是数字估计里的锚定（后来的多实验室重复里明显出现，但测的是估数量，不是定价页）；无关数字拉动愿付价重做后偏弱，第三档只在属性被写成数字时稳定出现，得失框架放到日常价格反应上仍有争议，其余多为从业者自述、思想实验或小实验。
- **不在这张卡里**：新品到底定多少（成本加成、按价值定价、对标竞品，来源都没讲）；涨价怎么执行（涨多少、怎么跟老客户沟通）。

## 先问这几个问题

1. 买家对这类东西有没有自己的参考价？常买、懂行的人，你的数字能挪动的范围很小；第一次买、对成本没概念的人，你摆出的数字才是在替他划定什么算合理。
2. 你要做的价格动作（涨价、降价、取消优惠、加赠品），买家会归入得到还是失去？他此刻的基准是什么：期待的价、以前见过的价，还是同行的价？
3. 买家做决定的那一刻，你放出的数字还在他脑子里吗？它有没有和他要估的东西放在一起比？
4. 买家能不能走开、转去别家、直接比价？来源里的实验对象多半走不开，这决定效应还剩多少（判断）。
5. 你手里的「愿付价」是怎么得来的：问出来的单个数字，还是真付了钱？

## 打法

### 1. 先查买家有没有参考价，再决定先摆哪个数字

买家有现成参考价时，你的数字能挪动的范围小；没有时，价格本身可能就是线索。
1. 判断买家的熟悉程度：常买、懂行，还是新品、一次性的外地客、低频商品。
2. 他没有参考价时，你摆出的第一个数字、最高的一档、卖场环境和规格，都可能在替他定义合理价。
3. 查数字能不能留到决策那一刻：重要的决定会被反复斟酌，数字要难忘到每次回头想都想得起来；还要看它有没有和待估的东西放在一起比，买家在估「这东西值多少」时容易被数字吸过去，拿它和另一样东西比时反而可能被推开。这几条是转述几位研究者的说法拼成的条件清单，不是预测公式；「重要的决定会被反复斟酌」只引了一句现场研究，没给出处。
- 做到什么程度算完成：你说得出买家有没有参考价；没有的话，你的第一个数字是什么，他做决定前还会不会再看到它。

### 2. 别把问出来的愿付价当成买家的固定价签

同一个买家的出价会随问法、描述甚至无关的数字变（最后一项后来重做得很弱），他自己往往也不知道。
1. 问卷或访谈得到的数字，要当成依赖提问方式的读数，不是价签（判断）。
2. 同一个方案换种说法再问一次，反应变了，说明测到的一部分是说法而不是偏好（判断）。
3. 实验里同一批人对不同东西的相对估价比较稳，绝对出价却容易被牵着走（这一半重做后偏弱）；前一半后来没被直接挑战，也没被逐条核对。
4. 你给早期用户报的第一个价，可能成为他们后续比较的基准；排整条产品线的价格时先想到这一点（判断）。
- 做到什么程度算完成：手里每个愿付价数字，你都标得出是怎么问出来的、换过说法没有。

### 3. 设档位：第三档能转移份额，但当成要测的假设

一项选酒实验里，加一个几乎没人选的选项，就把选择推向了想卖的那一档。
1. 先定想让买家多选哪一档：想推便宜档，在它下面放一个更便宜、更差的；想推高档，在它上面放一个更贵、只好一点的。
2. 陪衬档自己应当很少人选；买家要是在价格和质量之间权衡、又难以自己分辨质量，才更可能灵，能亲身体验产品时往往不灵。
3. 留意买家怎么给自己找理由：选中间档的人说最便宜的说不定不好、最贵的可能是宰人，居中比较稳妥。
4. 在自己的定价页上做对照，看真实购买，不看纸面选择。
- 做到什么程度算完成：你有一份「有这一档 / 没有这一档」的真实购买对照（判断）。

### 4. 涨价或降价之前，先查参照点

买家把一件事算作得到还是失去，取决于他的基准点；同一个人换个基准点，会从保守变成冒险（用到价格动作上是推断，见第 2 步）。
1. 写下买家此刻的基准：期待价、以前见过的价、同行价。
2. 判断你的动作会被归入收益还是损失。来源没有把这个框架落到具体价格动作上，这一步是推断，买家的基准也看不见，要自己问、自己测。
3. 查卖方有没有被旧高点锁住：泡沫破裂后，卖家把高峰价当基准，按当时市价成交就成了损失，成交很少，适应可能要好几年（来源只是一段没有数据的叙述）。
4. 面对确定的损失，人倾向于去赌，而不是接受确定的小损失；同一股力量也可能让人守着旧价不降（后半句是判断）。
- 做到什么程度算完成：每个价格动作你都写了买家的基准、会被读成得还是失，并标明是推断还是问出来、测出来的。

### 5. 检查价格传出的信号，要涨价先看买家记不记得住

1. 买家时间有限、除价格外没有别的线索时，太便宜的档可能被读成「有问题」，最高价的档既抬高感知价值，也让别的价格显得划算；这只是从业者自述加提出者的归因，没有对照。
2. 想定得比同行贵时，先想买家凭什么判断「公平」：同一个价格，放在朴素的场合被读成宰人，放在有配套的场合算公平。来源只有一个思想实验和提出者的观察，没检验过。
3. 要涨价，先把价格项分成天天买、记得很牢的，和不常买、记不住上回价格也不知道成本的；候选先从后一类里挑。零售从业者的说法是盯紧最常卖的几百样，在冷门品上找利润。
4. 买家没注意到不等于不会发现，发现后的被宰感可能把这点利润吃回去（判断）。这是线下零售的做法，订阅或软件里哪些收费项算低频并不明确，要自己用数据判断。
- 做到什么程度算完成：候选涨价项已按「记得住 / 记不住」分好类，并决定先小范围测哪几项，而不是一次全涨。

## 常见的坑

- 把「摆个高价就能抬高愿付价」当成已证事实。来源里的锚定其实是三类证据：先比较再估数量（重复得最强）、无关数字拉动愿付价（重做后偏弱）、价格被当作质量线索（没有对照）。
- 把实验里的倍数当定价参数。感受翻倍要价格涨到好几倍来自评分，第三档的份额变化来自纸面选择，都不是真金白银的购买；高位组出价是低位组的三倍多出自拍卖，中标者真付钱，但后来重做只看到很弱的锚定。翻译成档位间距，来源也没走这一步。
- 不加改动地搬到订阅、软件、企业客户：来源的例子几乎全是零售、拍卖、陪审和酒。

## 两派看法

**第一组：价格涨了感受只涨一点，还是价格本身就是质量？**

**一派：感受长得比金额慢。** 让学生给手表评分，合意度翻倍要价格涨到好几倍，按这个读法，按成本线性加价、或用「多付一倍就多一倍价值」去说服，可能对不上（判断：来源没走这一步）。

**另一派：买家没有别的依据时，价格会被当成质量的线索。** 感知价值随价格上升，最低的档反而可疑。

怎么选（判断）：两者讲的是不同的事，一个是对金额的感觉，一个是用价格推断质量。买家没有别的判断依据时（新品、一次性的外地客），按后一种用，并检查最低档；买家熟悉品类、能比价时，按前一种用，别指望加价换来等比例的感受，逐档测。

**第二组：高开价会被惩罚吗？**

**一派：不会。** 模拟陪审实验里，索赔额从百元级拉到十亿级，裁定额一路上涨，只是越往后涨得越少，没找到报复性压低的证据。

**另一派：放错场合会被读成宰人。** 同一个价格，在朴素的场合是敲竹杠，在有配套的场合算公平。

怎么选（判断）：对方走不开、又没有别的卖家可选时，高开价没被惩罚；买家能走开、能比价时，惩罚很可能不是压低成交价而是干脆不成交，这个实验测不到。提出者自己也说它排除不了反弹。

## 什么时候这套不管用

- 买家常买、懂行、记得价格：数字能拉动的范围小，涨价也会立刻被注意到。
- 买家能直接比价、有替代品：来源里的实验对象多半走不开，效应还剩多少不知道。
- 引用的结果多是评分、估价或纸面选择；手表又是带地位属性的商品，功能性工具、企业软件上的价格感受是否同样被压缩，没有证据。

## 例子

- 一个靠外地游客撑场的演出市场里，几位制片人自述：座位定得太便宜，人们会觉得有鬼；其中一位把前排和大部分包厢配成最高价，说这样很快卖光，分成多个价位时只有最高价位卖光、便宜座位空着。另一座公营露天音乐厅多年来把最远的一档票定得极低，常常无人问津，最贵的座位却一票难求。教训：只有自述和讲这个案例的人的归因，没有对照；「很快卖光」也可能是价定低了，座位远近、购票渠道等原因也没排除。用法是检查自己的最低一档。
- 一项啤酒选择实验：商学院学生在高档款和廉价款之间选，选高档的人数是廉价款的两倍。加一款更便宜更差、没人想买的，选廉价款的比例从约三分之一升到将近一半；改加一款更贵、只好一点的，约一成人选它，其余几乎全选原来的高档款。
- 一家大酿酒商大力推超高档新品后，主力品牌反而登上销量第一，总销量一起涨；诱饵效应论文的研究者事后解释，新品让主力显得没那么贵。没有销量数字，其他原因都没排除，只能当作相容的故事，不是检验。

## 证据有多硬

- 数字锚定（先比较、再估一个数量）：后来的多实验室重复里，每道题都出现了明显的锚定，效应还比原研究大，这是整张卡里证据最硬的部分之一。但它测的是估数量，不是定价页上的无关数字；来源里的具体数值是转述，没核对原论文。
- 无关数字拉动愿付价：原拍卖实验里高位组出价是低位组的三倍多。后来重做这个设计，对常见商品只发现很弱的锚定，对彩票完全没有，所以这个量级别当预期。
- 第三档：原实验对象是学生。后来对三十八项研究的系统梳理发现，效应基本只在属性被写成数字时稳定出现，买家亲身体验产品或有图像等感官信息时就消失；另一批大规模尝试里，九十多次只有十一次得到可靠效应。
- 得失相对于参照点：风险选择任务里，后来跨近二十个国家、四千多人的重复复现了大多数效应。但损失在日常无风险的价格反应里是否总体更有分量，一篇综述认为证据不支持，仍有争议；损失厌恶系数 1.5 到 2.5 只是平均值，因人而异。
- 感受随金额被压缩：一个受控实验加几个课堂小实验，来源里没看到系统重复。票价当质量线索、同款酒的场合差异、超市涨价顺序，只是从业者自述、一个思想实验和提出者的观察。高开价没被惩罚来自两个模拟陪审实验，其中一个是对大学生提出的假想案例。
- 来源把锚定归在「无意识线索」这个大类下。同一大类里「环境线索改变行为」那一层（看到某类图像人就变自私之类）后来被独立重复推翻，该层的提出者公开收回；数字估计是另一类证据，别因为同属一个大类就一起扔或一起留。

## 一页清单

- [ ] 我写下了买家有没有参考价；没有的话，我的第一个数字是什么
- [ ] 手里的愿付价都标了是怎么问出来的，换过说法测过
- [ ] 每个价格动作都写了买家的基准和会被读成得还是失
- [ ] 想过最低一档会不会被读成「有问题」
- [ ] 加不加第三档，准备用真实购买做对照
- [ ] 要涨价时先把价格项按「记得住 / 记不住」分类，打算先小范围测

## 这张卡没覆盖的

- 新品到底定多少：成本加成、按价值定价、对标竞品，来源都没讲
- 怎么测支付意愿、怎么做价格测试：对照测价、分档试点、给早期用户差异化定价
- 涨价的执行：涨多少、怎么跟老客户沟通、怎么过渡
- 折扣的长期代价与设计：折扣频率会不会拉低参考价，优惠券怎么设
- 套餐、捆绑、订阅阶梯、免费、尾数定价，以及退款承诺、效果保证这类「确定性」本身值多少钱
- 企业客户、订阅、软件的定价
- 买家有替代品、能比价时，这些效应还剩多少；需求曲线和价格弹性怎么实际估计
- 合规与信任成本：单位价格标示一类规则，以及被识破成宰客的代价
