# 股权与合伙人

> 以下基于中国大陆公司法与税法的一般做法，法规会修订；涉及持股比例、章程条款、持股平台、税务的，落地前请找当地律师和税务顾问核对。这张卡依据的材料按成稿时的旧版公司法和税政写成，文中的百分比、税率和门槛只当作「该去核对哪几个点」的线索。

合伙人之间代价最高的错误常出在开头：第一次定下的比例会成为日后所有谈判的参照点，而业务一变，谁贡献最大也会变；同时持股比例并不等于话语权，章程、协议和持股平台都能让表决权与出资脱钩，只是各有代价。这张卡分三步：先过「比例会固化」这一关，再把调整和退出写成事先定好的规则，最后弄清自己站在哪条持股线上、手里有哪些控制工具。

## 速览

- **法域提醒**：基于中国大陆公司法与税法、2024 年 7 月 1 日新《公司法》施行之前的一般做法，公司不在中国大陆注册的不要套用其中的持股线。
- **最关键的问题**：初始比例是按出资、按当下分工还是按将来的贡献定的？有人干一年就走，他手里的股份怎么办，章程写了强制回购吗？我的表决权在 34%、51%、67% 哪条线的哪一边，章程改过吗？
- **首选打法**：① 分股前先过「初次比例会固化」这一关：趁引入投资人之前，把每人的比例、各自在哪条线、分歧时谁拍板、以后按什么规则调整写在纸上并互相认可；② 分期兑现加强制回购：股权拆成立即兑现和分期兑现两段，提前离开的人只带走已兑现的部分，回购人、价格和流程写进章程；③ 控制权，先认清持股线再看章程能改什么：按默认规则，有限公司 7 类大事须 2/3 以上表决权同意，34% 至少能拦住，51% 没到 67% 仍独立决定不了，章程能改写十几项默认规则。
- **最常见的坑**：以为持股 51% 就能说了算（按默认规则，没到 67%，7 类大事仍独立决定不了）；以为签了一致行动协议控制权就稳了（到期会失效，目的达成后可能被解除，继承和转手时约束不到新的持有人）；只按出资分股、什么都不约定（合伙人一年后离开，仍占大股且不肯退，或愿意退但价格扯皮）。
- **证据**：绝大部分是一位股权实务从业者的经验和单个案例，没有对照数据；相对硬的是有法条依据的部分和一致行动协议失效点的上市公司实例，但法条是旧版的，税率和优惠口径也是几年前的，只能当提醒。
- **不在这张卡里**：期权池该预留多少、成熟期多长、行权价怎么定；融资条款（反稀释、否决权、对赌）。

## 先问这几个问题

1. 初始比例是按出资、按当下分工，还是按将来的贡献定的？业务还在试错的话，半年后贡献最大的还会是现在这位吗？
2. 有人干一年就走，他手里的股份怎么办——章程写了强制回购吗？谁回购，按什么价？
3. 我的表决权在 34%、51%、67% 几条线的哪一边？这些线按出资算还是按表决权算，章程改过吗？
4. 对方入股想要什么，和我们的长期目标一致吗？我让出了哪些权利，他将来能不能不经我同意转手？
5. 我是想长期持股，还是近期就套现？这决定持股平台怎么选、税怎么算。
6. 合伙人之间现在「只是看法不同」的地方，哪些一年后会变成分歧？到时谁拍板、怎么分手，事先说好了吗？

## 打法

### 1. 分股前先过「初次比例会固化」这一关

股权价值一旦显性化（比如投资人给了估值），再调整就极难，所以要趁引入投资人之前理顺结构。
1. 先用清单自查隐患信号：均分、创始股东超过 3 人、给兼职者或一次性资源提供者大量股权、小股东在实际操盘、没有退出机制、外部投资人控股、未实缴注册资本过高、配偶股权没做到钱权分离、章程直接用工商范本。答「是」满 3 项，就该对股权结构做深度测试（来源只建议要做，没说怎么做）。原清单里个别题答「是」反而是做对了（如考虑过退出机制），这里已统一改写成「有隐患」的说法（判断）。「3 项」没有给理由，只是粗筛；未实缴资本一题的标准受新公司法影响，不能照用。
2. 三人平分时，登记通常要写整数百分比，多出来的 1% 给谁，决定了谁站在 34% 线上。
3. 均分的风险是分歧时没人能拍板，而时间是创业最贵的成本；不过持股均分不等于表决权均分，章程可另设决策规则（见打法 3；这是综合判断，来源没把两者连起来）。
4. 业务还在试错时，价值最大的人可能会换；比例一次定死又不留调整空间，股权就会跟不上（办法见打法 2）。
- 做到什么程度算完成：每个人的比例、各自在哪条线上、分歧时谁拍板、以后按什么规则调整，四件事写在纸上并互相认可。

### 2. 把调整和退出写成规则：分期兑现加强制回购

创业之初没人知道谁贡献更大，比例又得先定；办法是事先规定提前离开的人只带走已兑现的部分。这套做法源自海外创投圈，在国内要改造才能落地。
1. 把每位创始人的股权拆成两段：创立时立即兑现一部分，其余分期兑现。例：立即兑现 20%，其余 80% 分 4 年；持股 30% 的人满一年离开，带走 6%（30%×20%）加一年期的 6%，共 12%，剩下 18% 由其他人按原始出资价回购。
2. 周期 3、4、5 年都有人用，试错越长周期可能越长；可以每年平均或逐年递增，也可以设「满一年才给第一笔」的门槛。来源里「国外通常几年」的说法前后不一，别把任何数字当标准。当下实在看不出谁贡献大，就只兑现一部分，其余留到之后由股东会按贡献协商分配。
3. 写进章程，并事先定好：触发情形（被辞退、除名、自己离职、退休、死亡）；谁回购未兑现部分（除离开者外全体股东按比例、最大股东、公司减资，三选一；旧公司法下公司一般不能持有自己的股权）；回购价格（来源列的选项有原始出资额、原始出资加年化利息、上一年度经审计净资产）和流程。不写进章程，回购可能缺乏法律依据；回购价格是敏感地带，事先没写明，可能因价格分歧让整套兑现机制落空。
4. 另外约定：有限公司改成股份公司时章程要重新约定，兑现安排可能失灵；被收购、合并、分立时，未兑现部分怎么处理。
- 做到什么程度算完成：比例、周期、节奏写成数字；回购人、价格、流程、违约责任有章程条文，并经股东会通过。

### 3. 控制权：先认清持股线，再看章程能改什么

1. 在有限公司，修改章程、增减注册资本、合并、分立、解散、变更公司形式这 7 类事项，默认须有 2/3 以上的表决权同意。所以 34% 至少能拦住它们；51%（常被叫「绝对控股」）没到 67% 就独立决定不了；67% 才是最完整的控制权。这些线按表决权算；51% 和 67% 两处判断都带「除非章程另有约定」；章程能把 2/3 的门槛调高，还是也能调低，来源没说清，须律师核对。
2. 持股太低，连召集会议、请求解散这两项程序性资格都没有：表决权不到 10%，没有资格请求召开临时股东会议或请求法院解散公司（来源只是一桩没有结局的咨询，没讨论低于 10% 还有没有别的路）；但 10% 只是资格，法院还要看是否属于列举的僵局事由、是否「通过其他途径不能解决」。
3. 有限公司的章程能改写十几项默认规则：分红与增资认缴不按出资比例（须全体股东约定）、表决权不按出资比例、股权对外转让的同意权和优先购买权、股东资格能否继承、议事与表决程序、董事长怎么产生等。拿它当和律师谈章程的议程，别直接用工商范本。
4. 早期用有限公司，别为将来上市一步到位注册股份公司：股份公司取消了上述章程自治，转让股份时其他股东没有优先认购权，更容易失控；等真要把股权结构对外打开时再改制。
5. 控制权条款要在引入外部股东或自己开始减持之前写进章程：改章程要股东会表决通过，临阵才改既可能票不够，也可能因时机敏感被质疑；争夺的主战场是董事会席位。

### 4. 票不够时：一致行动协议还是有限合伙平台

两种工具都能把分散的表决权集中到你手里，各有短板。提出者认为一致行动协议的效力不如有限合伙平台，但合伙平台对想长期持股的人有税务代价，来源没有给出统一排序。
1. 一致行动协议：几个股东先在股东会之外商量出对外唯一的意见再去投票，不照办的按协议受罚。例：创始人直接持股二十出头个百分点，签协议后可支配的表决权到四十几个点——按上面的线，能拦住 7 类大事，但仍不能独立决定（判断）。
2. 先问三个失效点：到期怎么办（协议一般有期限，期满即失效；来源的例子写明不再顺延）；为上市等目的签的，目的达成后会不会被解除；签约人去世、股权被继承，或股份上市后在交易所转手，新持有人受不受约束。补救是写进章程以增强对第三方的效力，但来源没解释为什么有效、有效到什么程度。它是退路：小股东不肯放弃直接持股时才用。
3. 有限合伙持股平台：创始人当普通合伙人，用很小的出资掌握平台里的表决权（来源的例子是 1% 出资掌握 70% 以上控制权），其他人当有限合伙人只拿收益。
4. 但想长期持股的人要先算税：退出税率各地口径不一（财产转让所得 20%、经营所得 5%～35%、区分两类合伙人，三种都有）；持有期分红个人合伙人缴 20%，持股公司取得分红可免企业所得税；个人经合伙企业间接持股，还享受不到直接持股的部分优惠。口径是几年前的，其中一处依据的文件后来被撤回。
5. 别追税收洼地：地方的核定征收、财政返还一旦与国家税法冲突，书面协议也无效，随时会被追缴；来源的结论是只适合有短期套现意图、要缴巨额税款的人，不适合做长期规划。

### 5. 引入大股东或投资人之前，先问目标诉求再谈价格

缺钱的一方和有钱有资源的一方一拍即合；但股东关系是长期的、不只靠钱维系的，目标不同，日后就会出问题。不要求目标完全相同，大概相同、小处存异即可。
1. 问你让出了什么：近八成股权，等于把掌舵位置和对方将来转手的主动权一起让了，这个比例高于 67% 线（判断）。
2. 来源只提出了「让出什么权利、对方能否不经我同意转手」这两个问题，没说用哪些条款解决；对某个投资方「几层用意」的描述是提出者的推断，只能当提醒。

### 6. 给员工留股权：池子放哪、平台选哪、价格会不会进账

对象主要是打算上市后减持的员工；来源的例子全是上市或拟上市公司。
1. 预留池的一种做法：创始人设有限合伙企业并当普通合伙人，由一位内部人代持其余份额，把退出合伙人的股份或各方转出的小比例放进去，授予时再过户给员工；代持是因为认缴制下每份股权都得有人认缴。打算境内上市的，申报前要解除代持，已授予未到行权期的期权一般也要解除。
2. 平台怎么选：员工直接登记，人人有表决权，审核期要签大量文件、离职还要走退出程序；持股公司，上市后减持过企业所得税和个人所得税两道，合计 40%；合伙企业只缴一次税，还能钱权分离。来源里合伙企业的 20% 是某地口径，地方财政返还属于地方优惠，别计入。
3. 拟上市公司给员工低价股权，可能被认定为「股份支付」：差额计入费用、减少利润，员工还要缴个税（满足 7 条条件并备案的可递延到转让时）。公允价值没有硬性标准，靠券商和会计师判断，离申报期越远越宽松；先问他们：授予价低于公允价值吗，怎么论证，利润受得了吗。

## 常见的坑

- 以为持股 51% 就能说了算：按默认规则，没到 67%，7 类大事仍独立决定不了，而 34% 能拦住它们。
- 以为签了一致行动协议控制权就稳了：到期会失效，目的达成后可能被解除，继承和转手时约束不到新的持有人。
- 只按出资分股、什么都不约定：合伙人一年后离开，仍占大股且不肯退，或愿意退但价格扯皮。

## 两派看法

**一派：靠选人减少矛盾。** 股东关系是长期的，入股前要看目标诉求是否大致一致、能否互相信赖、节奏是否同频，别只看谁给钱给资源。

**另一派：默认矛盾从第一天就在。** 合伙之初「只是看法不同」的地方，常常是日后决裂的种子，该当作还没激化的矛盾提前安排，而不是靠感觉上的融洽。但这是一种观察纪律，不是可检验的预测：证明不了合伙一定会散，还容易把分工互补的差异误当成冲突。

这一组不必二选一：挑同频的人，同时仍写好退出和调整规则。

**一派：拖不起，早点把拍板权和调整规则定清楚。** 创业期时间最贵，久拖不决很容易拖垮公司。

**另一派：内部分歧要留改正的机会，别一上来就当敌我处理。** 严肃指出错误，同时留出改正余地，过火的斗争不当；只有对方坚持并扩大错误，才发展成对抗。它没回答「谁来认定对方在坚持错误」。

怎么选（判断）：两者管的是不同阶段。事前的东西——比例、拍板权、兑现、回购价——要快、要写死，这正好补上「谁来认定」的空缺：用事先写好的离开情形和价格，代替事后争谁对谁错。事后真出了分歧，先走缓和路线，前提是双方仍有共同目标、仍在同一个组织、对方还有改正的可能；这些前提不成立时（比如一方已在转移资产），缓和路线就不适用。工具上，小股东肯改成间接持股、你又想长期持股的，先算税；不肯的，才退到一致行动协议，并写进章程。

## 什么时候这套不管用

- 公司不是有限公司：股份公司不能再通过章程约定那十几项规则，原来靠章程做的安排（包括兑现）要重新设计。
- 持股线只是默认规则，章程一改，线就会移动。
- 上市或挂牌公司：持股线、二级市场举牌和监管都不同；未上市公司的股权危机多是股东内讧，而不是外部对手收购。
- 想长期持股、没有套现打算：合伙平台有税务代价，税收洼地更不合适。
- 早期公司什么时候搭员工持股平台、人很少时有没有必要，来源没讲；回购价对以劳务入股、没出过钱的创始人意味着什么，也没讨论。

## 例子

- 三兄弟说好各占三分之一，登记只能写整数，于是一人 34%、两人各 33%。两年后理念不合，那两人想换掉董事长，才发现要先改章程，而持 34% 的人不同意，议案永远通不过。提出者据自己代理过的一场诉讼改编。
- 一家靠个人出镜的内容公司：起步时推的人占大头、出镜的人占小头，当时合理；走红后核心价值转到出镜者身上，股权仍在对方手里，战略又谈不拢，两年后体面散伙。讲这个案例的人称这是「必然」，那是事后判断。
- 一家电商公司为熬过融资寒冬，让一家大机构拿到近八成股权；对方后来把股权转卖给更大的买家，创始人只能被动接受，几年后被清退。来源没有对照「保留否决权或转让限制能否改变结局」。
- 一家上市公司的控股股东连续减持，持股从五成多降到一成出头，对手在二级市场吸筹成了第一大股东；之后才修章程设门槛，因时机敏感被监管质疑而撤回，公司几近退市。讲这个案例的人说若减持前就改章程，对手「也许」会忌惮，这是带「也许」的反事实。

## 证据有多硬

- 绝大部分是一位股权实务从业者的经验和单个案例，没有对照数据；案例多是对公开信息的重述，动机归因（对方有几层用意、「必然散伙」）是提出者的推断，不是当事人的说法。
- 「三人各占三分之一，九成多会失败」是一位投资人口头说的，没有统计来源，也没有均分却成功的案例对照。
- 相对硬的是有法条依据的部分（持股线、章程可约定的事项、10% 的门槛）和一致行动协议三个失效点的上市公司实例；但法条是旧版的。股权兑现的国内落地要点是提出者的实务总结，来源只给出一个法院支持章程强制回购的判例。
- 税率、优惠、股份支付的口径是几年前的，部分政策已被清理、文件已被撤回，只能当提醒，不能用来算今天的账。

## 一页清单

- [ ] 每个人的比例、各自在 34%、51%、67% 哪条线的哪边、分歧时谁拍板，都写在纸上
- [ ] 兑现比例、周期写成数字；强制回购、回购人、回购价、流程写进了章程
- [ ] 章程不是工商范本：表决权、分红、转让同意权、议事规则都过了一遍
- [ ] 若用一致行动协议：到期、目的达成、继承与转手三处失效点问过律师
- [ ] 对方想要什么、我让出哪些权利、他转手时我有没有发言权，问清了
- [ ] 先想清楚长期持股还是近期套现，再选持股平台；税收洼地不当长期方案
- [ ] 给员工低价股权前，向会计师和券商问过对利润和个税的影响
- [ ] 以上涉及的法条、比例、税率，都请律师和税务顾问按现行规定核对过

## 这张卡没覆盖的

- 期权池该预留多少、成熟期多长、行权价怎么定、不同层级怎么分（来源里的 10%、2% 只是示例，上市公司的激励比例规定不能当创业期的预留比例）；员工离职时已授予的股权怎么回购
- 股份公司、新三板、上市公司的其他持股线；委托投票权、优先股、双层股权等其他控制权工具
- 有限合伙平台里两类合伙人的具体控制机制怎么约定
- 怎么向合伙人开口谈比例、怎么量化各人的贡献
- 融资条款：反稀释、否决权、对赌；离婚、继承对股权的影响
- 自查清单命中 3 项以上之后，「深度测试」具体测什么
- 现行法下的具体条文、税率、股份支付口径
- 合伙人真的决裂之后怎么谈、怎么走法律程序
