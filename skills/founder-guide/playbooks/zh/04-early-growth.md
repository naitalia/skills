# 早期获客与增长

这张卡把拉新、留存和让人主动传开放进一个先后顺序：先选一个反映用户真正用上产品的活跃指标，再看漏在拉新还是留存；拉新先算账再选渠道，留存先量对再改产品和上手引导，传开分产品内推荐和内容口碑两层，证据强度差很多。渠道和平台的名字很快过时，这里只讲怎么筛选、怎么判断。

## 速览

- **最关键的问题**：从不知道你到体验到核心价值，哪一步漏得最多，是漏在拉新还是留存？一个用户一生能带来多少钱、获取他要花多少，你的盈利方式撑得起哪类渠道？产品本身有人喜欢吗，没有的话，推荐和拉新换来的多半只是一阵热闹。
- **首选打法**：
  - **先选活跃指标，再画漏斗**：选一个反映用户体验到核心价值的绝对数活跃指标，把旅程每一步配上一个数（估算也算）。
  - **没钱投广告：先算账，再筛渠道，再小测**：用户一生价值要大于获取成本；筛出渠道后小测，追踪成本和用户价值，再决定加码、改策略或放弃。
  - **用户留不住：先量对，再改产品和引导**：用关键行为和同期群曲线量留存，先改产品和新用户引导，最后才是邮件和推送。
- **最常见的坑**：用登录定义留存；选了和产品特点不符的主渠道、对不见效的渠道不设退出，或依赖单一渠道、单一平台的接口；把「同时用几个功能的人留存更高」当成因果。
- **证据**：指标、漏斗、渠道和留存这几套主要是一位从业者的长期经验，没有对照数据，案例都是单个案例或事后叙述；口碑一层的六个问题是从已传开的东西里事后归纳的，没拿没传开的做对照。
- **不在这张卡里**：零预算冷启动的具体做法（最早的十个、一百个用户从哪来，怎么手工拿到）；怎么找到关键行为和激活点。

## 先问这几个问题

1. 你现在盯的是累计注册这类只增不减的数，还是反映用户体验到核心价值的活跃数？
2. 从不知道你，到体验到核心价值，旅程里哪一步漏得最多？漏在拉新，还是漏在留存？
3. 一个用户一生能给你带来多少钱，获取他要花多少？你的盈利方式撑得起哪一类渠道？
4. 产品本身有人喜欢吗？没有的话，推荐和拉新换来的多半只是一阵热闹。
5. 你以为的口碑，有多少是能追踪的线上数字，多少发生在你看不见的地方？

## 打法

### 1. 先选一个值得盯的活跃指标，再把旅程写成漏斗

累计注册是只增不减的静态数字，带虚荣成分；日、周、月活的总数趋势用来看留存也不行，它是新增和流失的汇总，新用户可以把流失盖住。
1. 选指标时逐条问：能不能看出用户体验到了核心价值；反映当前活跃还是累计；它变好是否说明整个公司在变好（别漏掉供需的另一侧）；团队容易理解吗（建议用绝对数）；先导还是滞后；变差时你能做点什么。不必一步到位，目的是给团队现阶段的聚焦点。
2. 画出用户旅程，每一步是用户的一个动作（判断），每步配一个指标，没数据先估，同时开始追踪。先只定三个最重要的一级事件，能画出基本漏斗再往下加。
3. 把总活跃写成「新增部分 + 已有用户部分」的公式，找最大瓶颈，并按渠道、设备、新老用户分群看。目测可以起步；但转化率最低的一步不等于对总量影响最大的一步，要代入数字做假设推演（判断，由来源里的示例数字算出）。
- 做到什么程度算完成：有一个绝对数的活跃指标，一张每步都有数（估算也算）的漏斗，说得出此刻该动的一两个变量以及为什么。

### 2. 没钱投广告：先算账，再筛渠道，再小测

用户一生带来的价值要大于获取他的成本，否则拉得越多亏得越多（提出者承认特定情况下可以短期为之，长期不可持续）；盈利方式还决定你撑得起哪类渠道。
1. 用户一生价值 = 会用多少个月 × 每月平均能赚多少，是否扣毛利自己定。早期数据少，这只是估算，估得越乐观越容易自欺（判断）。获取成本要算全，企业客户产品还要加会议、内容、销售人员的薪资差旅，并单看你能控制的付费渠道，别和天然来的用户混算。
2. 对照看撑得起哪类渠道：免费产品自身赚的钱撑不起长期付费增长，免费渠道可能是唯一选择；价值高到养得起销售团队，才谈销售。比值大于 3 只是不少风险投资对订阅软件公司的期待，别当通用门槛。
3. 选渠道五步：认产品，认用户（他们在哪里），列备选，按五条标准筛（体量大、免费或便宜、可追踪、能精准定位、可随时开始和停止），再小测并追踪两个数：成本最低的渠道，和来的用户留得最久、价值最高的渠道。目标是低成本带来高价值用户。
4. 测完逐个处置：好的加码，差的改策略重测，始终不改善就放弃或只留很低的预算。多数产品真正做得大的只有一两个渠道，但也别押单一渠道。
5. 五条标准在来源里并列、没排序；预算很小的团队可能更该先看可追踪、可随时停，体量大要等验证之后才重要（判断）。先用漏斗看哪里漏，再去开新渠道。
- 零预算时，这套选渠道流程里唯一具体的一句：销售类渠道最开始靠人工一个一个宣讲、做演示，找到最好的方式再做成可重复的流程。
- 做到什么程度算完成：每个测试渠道都有成本和用户价值（短期可用激活比例、付费比例代替）两个数，并有加码、改策略或放弃的结论。

### 3. 让人传开：产品内推荐和内容口碑是两层

产品内的推荐成本低、用户质量好、转化高；一家孵化器对三十多位增长专家的调研里，超过七成把它列为早期最重要的渠道之一（主观排序，样本小）。
1. 把邀请放在可分享的时刻（新用户刚注册、刚完成一项任务），不藏在静态菜单里；再拆成几步找瓶颈：看到入口的比例、邀请页转化、人均发出几个、被邀请人点开、点开后完成注册。
2. 别把「每个老用户至少带来一个新用户」当目标：这几乎不存在，或只能持续一小段时间；低于这个数，推荐仍然性价比很高。
3. 内容口碑一层，用六个问题检查你想让人谈论的东西：谈论它会让人显得更灵巧、更富有、更时尚吗；什么环境里哪个线索会让人想起它；它激发的情绪是促进分享还是破坏分享；别人用时旁人看得见吗；能帮人省时间或钱吗；有没有会被人讲起的故事。六条不必齐备，这是检查清单，不是配方。
4. 先问内容值不值得传，再找人：知名人士的亲和力不足以让东西传开，但这不等于关键人物无用，冷启动时请对的人让第一批人看到可能仍有价值（判断）。别指望每个人再转给好几个人，传播链很短，要做的是降低每一步的损耗（判断）。
- 做到什么程度算完成：推荐的每一步都有数、知道卡在哪；六个问题都过了一遍，知道哪几条最弱。

### 4. 用户留不住：先量对，再改产品和引导，最后才是邮件推送

流失在早期会被新增掩盖；钱买得到新用户，买不到留存，因为留存建立在产品对用户有价值之上。
1. 用关键行为而不是登录定义「留下」（回来基本就是来玩的产品，登录可能够用）；按天然使用周期计时，办法是找出至少做过两次关键行为的用户，看大部分人两次之间隔多久，再选按日、周或月计。
2. 画同期群曲线：把同一时期首次完成关键行为的用户归为一批，每个周期算其中仍在做关键行为的占比。好的曲线先降后趋平，一直往下要考虑产品是否还没和市场对上；改过引导后，新批次应当更平或更高。
3. 改法的顺序：先做产品改进和新用户引导，再谈邮件、推送；对没优化过的产品，前者的回报往往远大于后者（提出者的说法，没给各手段的对照数据），信息轰炸还会让用户疲劳。
4. 诊断用户没做关键行为的原因：动力不够、能力不足（太费劲、界面困惑），还是没有触发。再把留下的用户按参与度分层（消极、核心、超级），找出多数人卡在哪一级。
- 做到什么程度算完成：有一张按关键行为画的同期群曲线，知道它是否趋平、平在多高，也知道多数留存用户卡在哪一级。

## 常见的坑

- 用登录定义留存：有一小撮人登录很勤，却把产品当私人记事本用，试用期一过大多流失。
- 选了和产品特点不符的主渠道，对不见效的渠道不设退出，或依赖单一渠道、单一平台开放的传播接口：平台一改规则，来源就断。
- 把「同时用几个功能的人留存更高」当成因果：用得多的人可能本来就更投入。
- 同时开很多项指望碰中一个，或没有基本监测就上线。

## 两派看法

**第一组：可追踪的渠道优先，还是口碑多半发生在看不见的地方？**

**一派：渠道要能追踪。** 选渠道时可追踪优先，推荐用漏斗量化，这样才算得出成本和留存，才能加码或放弃。

**另一派：别把线上声量当口碑。** 提出者说多数口头传播发生在线下，线上不到一成（无出处）；线上评论因为看得见而被高估。以可追踪为先，天然偏向线上能量化的渠道。

怎么选（判断）：可追踪的做成漏斗和小测；不可追踪的，在注册或下单时问一句「你是怎么知道我们的」，估个量级。目标人群习惯面对面、受熟人影响的，线下权重大；重度线上社群的线上比例可能高得多，要在自己的人群里测。

**第二组：增长策略更重要，还是先把东西做实？**

**一派：获取用户是决定生死的另一半。** 产品成败越来越少靠新鲜功能，越来越多靠增长策略。

**另一派：先造实，再造名。** 过度造名是陷阱，消费者一想到价格里可能有一大块是广告费，产品就完了；靠造名取胜的主要是效用难以自己判断的消费品。那套关于盲从和媒体权威的社会条件已经过期，产品条件还成立（判断）。

怎么选（判断）：前一派自己也说钱买不来留存，两边在「先有值得留下的产品」上收敛。效果用户能自己检验、要重复使用的产品，留存说了算；效用说不清的消费品，造名确实有用，但不能急于求成。先造实再造名谈的是付费媒体砸出的名，内容口碑谈的是自然传播，别混在一起（判断）。

## 什么时候这套不管用

- 用户很少的极早期：每批同期群只有几十人，曲线抖动大，增长模型更像待验证的假设清单；这时可能先看每个新用户有没有完成关键行为更稳（判断）。
- 低频或一次性的产品（买房、装修一类）：价值不在重复使用，要看复购和推荐，不是留存曲线（判断）；关键行为没找对，整套曲线也量错了对象。
- 病毒式传播有产品条件：免费、没有门槛、很快得到价值、大家都需要、人越多体验越好；要存一段时间才看出回报的产品很难把它当主渠道。
- 选渠道的流程是围绕「花钱获客再算成本」设计的，零预算时第一批用户往往靠手工争取（判断）；平台规则和接口也会变。

## 例子

- 一款靠平台开放的发帖机制爆发式增长的社交应用，月活一度上千万，融资两个月后几乎缩水一半。创始人事后说，新用户进来没发现价值很快离开；而直接触发是平台关掉了它依赖的发帖机制。教训：证据主要是创始人的事后说法，渠道被掐断和新用户没发现价值两种解释并存。
- 一家产品很好却默默无闻的小家电公司，市场总监花几十块买道具，让老板穿白大褂把硬物放进机器碾成粉并拍成视频；讲这个案例的人说第一周几百万次点击，两年内销量涨了几倍。教训：无对照的成功个案，销量没给基数，看点就是产品性能本身，演示点不明显的产品能否照搬，案例没回答。
- 一个推出才一年多的电视品牌，花几百万拿下一场全国轰动的事件的独家赞助，当期知名度、购买意向、订货量都涨了，还被评为年度十大策划，一年后退出这个市场。中间的渠道、产品和价格战没交代，不能把失败归到这次营销；它和上一例都是「当期数字加讲这个案例的人的归因」，别拿一个去反驳另一个。

## 证据有多硬

- 指标六问、增长模型、五步选渠道、同期群四步，主要是一位从业者的长期经验，没有对照数据；案例都是单个案例或事后叙述。一个团队的模型里，改善新用户上手带来的日活增长半年后是一次性拉新的好几倍，那是模型输出，不是实验；留存复利算例也假设新增和流失比例恒定，只说明方向。
- 没注出处的数字别当基准：线上口头传播不到一成、两到五成购买决策受口头传播影响、某社交产品新用户月留存四成。
- 「不留存就去死」是修辞性很强的结论，证据只是两个案例加两个算例，且和「获取用户是另一半」并存，别单拎一句。
- 口碑那一层，没有任何一条原则给出检验数据，六个问题是从已传开的东西里事后归纳的，没拿没传开的做对照。后来的研究：同一位提出者的分析支持「有的情绪促进分享、有的破坏分享」（不独立）；独立团队的在线扩散研究支持「传播链很短」；一项计算机模拟支持「不必靠少数关键传播者」，但它是模拟，也不检验「内容本身决定传播」。

## 一页清单

- [ ] 有一个反映用户体验到核心价值的绝对数活跃指标，六问都过了
- [ ] 旅程每一步有数（估算也算），知道漏在拉新还是留存
- [ ] 算过用户一生价值和获取成本，知道自己撑得起哪类渠道
- [ ] 每个测试渠道都有成本和留存两个数，并有加码、改策略或放弃的结论
- [ ] 留存用关键行为和同期群曲线量，不用登录和总活跃数
- [ ] 先改产品和新用户引导，再动邮件和推送
- [ ] 不可追踪的口碑，在注册时问过「怎么知道我们的」

## 这张卡没覆盖的

- 零预算冷启动的具体做法：最早的十个、一百个用户从哪来，怎么手工拿到
- 怎么找到关键行为和激活点；用户很少时怎么判断留存，怎么用访谈弄清用户为什么走
- 补贴和邀请奖励的定价、防刷、合规
- 具体地区平台和渠道的做法（来源是十年前后的海外环境）；面向企业客户的获客
- 定价怎么影响用户价值和转化（见定价卡）
- 增长实验怎么设计、怎么判断显著；付费渠道的具体投放优化
- 内容传播的失败样本和对照；低频或一次性产品该看什么指标
