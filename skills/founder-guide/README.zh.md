# 创业参谋 · Founder Guide

[English](README.md) · **中文**

一个开源 skill：给 AI 助手和智能体 12 张按处境组织的打法卡，覆盖创业者最常卡住的那些决定——
从「真会有人掏钱吗」，到「要不要开掉这个高管」，再到「公司可能撑不过下个季度」。

它不是一份创业建议清单。每张卡只对付一类局面，并且都按同一个结构回答：

- **先问这几个问题**：先判断哪条建议适用于你
- **打法**：具体步骤，每一步写明做到什么程度算完成
- **常见的坑**：创业者通常怎么做错
- **两派看法**：有经验的人在哪里意见相反，按什么条件选
- **什么时候这套不管用**：适用边界
- **证据有多硬**：一条说法是大量观察支持，还是一次实验、一个人的经验，后来有没有被削弱
- **这张卡没覆盖的**：老实说出回答不了的问题

每张卡都有中文和英文两版。你用什么语言提问，助手就用什么语言回答。

## 安装

skill 本身就是 Markdown 文件，能读文件的助手都能用。这个文件夹（仓库里的 `skills/founder-guide/`）
就是整个 skill。

获取方法：打开仓库首页，点绿色的 **Code** 按钮 → **Download ZIP**，下载后解压。

**支持 skill 的智能体**：把 `skills/founder-guide/` 这个文件夹放进你的智能体加载 skill 的目录，
文件夹名保持 `founder-guide`。它会先读 `SKILL.md`，只在你的处境需要时才打开对应的卡。

**不支持 skill 的聊天应用**：把这个文件夹里 `SKILL.md` 的内容贴进应用的自定义指令（或项目指令），
再把 `playbooks/` 文件夹（或者只传你需要的一两张卡）作为项目文件上传。

**不用 AI 也行**：打开 `playbooks/zh/` 或 `playbooks/en/`，读你那个处境的卡。每张卡最后都有
一页清单，可以直接带进会议。

## 可以这样问

- 「最大的客户续约时要我降价三成，不降就走，怎么办？」
- 「合伙人想和我五五分股权，有问题吗？」
- 「我访谈了 15 个人，都说会用，够了吗？」
- 「这份行业报告说市场 400 亿美元、年增长 30%，能信几分？」
- 「现金只够撑四个月，下一轮融资没着落，接下来怎么办？」

## 内容是怎么来的

每张卡都是几种成熟实践流派的综合，用白话重新写成。每一句都对照来源核对过有没有说过头、
丢了限定条件或张冠李戴；案例全部匿名；有争议的地方把两边都摆出来，而不是压成一个答案。

## 后续计划

创业者常问、但这 12 张卡还覆盖得不好的处境：融资操作（过桥、条款清单、领投方撤出）、
现金跑道与资金规划、对单一大客户的依赖。下一步做什么，由真实案例决定——见「参与贡献」。

## 免责声明

这是帮助你想清楚决策的一般性指引，不是法律、税务、会计或投资建议。股权那张卡依据的是中国
大陆公司法与税法的一般做法，可能已经过时；落地之前请向当地律师和税务顾问核对现行规定。

## 参与贡献

最有用的贡献是一个打法卡没处理好的真实处境：开一个 issue，写清楚你问了什么、得到了什么、
缺了什么或错在哪里。
