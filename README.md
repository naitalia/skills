# skills

**English** · [中文](README.zh.md)

A collection of reusable skills for AI agents. Each skill lives in its own repository; this page
is the index.

## Skills

| Skill | What it does | Languages |
|---|---|---|
| [Founder Guide · 创业参谋](https://github.com/naitalia/founder-guide) | Twelve situation-based playbooks for the decisions founders get stuck on: demand validation, MVP scope, pricing, early growth, B2B sales, competing with incumbents, equity and co-founders, hiring and firing, managing a team, negotiation, judging claims and forecasts, and crisis decisions. | English, 中文 |

Each skill's repository explains how to install and use it. All skills are plain Markdown and
work with any assistant that can read files.
